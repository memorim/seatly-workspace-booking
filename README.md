# Seatly — бронирование рабочих пространств

Помогает выбрать переговорную или рабочее место и сохранить бронирование.

**Тип:** Самостоятельный портфолио-проект. Проект использовался реальными пользователями. В репозитории показана демонстрационная версия; масштаб и коммерческие показатели не заявляются.

![CI](https://github.com/memorim/seatly-workspace-booking/actions/workflows/ci.yml/badge.svg)

[Открыть интерактивное демо](https://memorim.github.io/seatly-workspace-booking/)

Демо GitHub Pages использует localStorage, не обращается к Express API и не синхронизирует данные между посетителями. Серверная версия запускается командами ниже.

## Что работает
- Каталог, поиск, фильтр типа пространства, выбор даты и времени.
- Создание бронирования, серверный расчёт цены, проверка вместимости и пересечений.
- Отдельное браузерное демо с сохранением изменений в localStorage.

## Стек
React, TypeScript, Vite, Express, SQLite, Zod.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

## Технические решения
- API проверяет пересечения интервалов; соседние интервалы разрешены.
- Цена вычисляется на сервере с учётом минут, а не берётся из запроса клиента.

## Границы готовности
- Не реализованы аккаунты, оплата, почтовые уведомления и подтверждение владельцем.
- Каталог, рейтинги и июльские даты — фиксированные демоданные. Часть кнопок навигации — элементы макета.
- Браузерное демо не использует сервер и не обеспечивает общую доступность мест между пользователями.
- В серверной версии проверка и запись бронирования рассчитаны на один процесс; конкурентные записи между процессами требуют транзакции и ограничений БД.
