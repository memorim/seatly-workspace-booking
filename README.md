# Seatly — бронирование рабочих пространств

Сервис поиска и почасового бронирования рабочих пространств: переговорных, кабинетов, лофтов и студий.

## Что реализовано

- каталог с типами пространств и быстрыми фильтрами;
- карточки с вместимостью, рейтингом, оснащением и ценой;
- календарь занятости выбранного пространства;
- расчёт стоимости на клиенте и сервере;
- серверная проверка вместимости, рабочих часов и пересечений;
- SQLite, seed-данные и интеграционные тесты API;
- адаптивная версия для телефона.

## Стек

React 19, TypeScript, Vite, Express 5, Zod, Node SQLite, Node Test Runner, Supertest.

## Запуск

Требуется Node.js 22.5+.

```bash
pnpm install
pnpm dev
```

Приложение: `http://localhost:5174`, API: `http://localhost:4200`.

На Windows можно запустить `start-local.cmd`: он установит зависимости, соберёт проект и откроет приложение на `http://localhost:4200`.

Production-режим вручную:

```bash
pnpm build
pnpm start
```

```bash
pnpm typecheck
pnpm test
pnpm build
```
