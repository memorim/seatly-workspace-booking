# Искусственное тестирование

Все роли и данные в этом раунде вымышленные. Браузерные контексты имитируют независимые сессии, а не реальных людей.

## Покрытые пути
Гость выбирает помещение, создаёт заявку; отдельная сессия владельца подтверждает; гость переносит и отменяет. Из 50 конкурентных запросов на один слот принят один, 49 получили 409. Конфликт переноса сохраняет исходную бронь. Просроченный pending освобождает слот и не подтверждается. Чужие заявки и анонимные изменения запрещены. Ошибка каталога 503 показывается с повтором.

## Воспроизведение
`pnpm test` → `pnpm test:e2e` → `pnpm measure`.

## Границы
Браузерные тесты используют локальные учебные identities. Нативный адаптер D1 отдельно проверен на localhost: доверенная identity, подмена заголовков, изоляция и атомарные изменения. Два независимых настоящих ChatGPT-аккаунта не использовались. Проверки клавиатуры и reflow не являются полной сертификацией доступности. Производительность локального теста не характеризует размещённый сервис.
